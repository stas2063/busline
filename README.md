# Busline

Одностраничный прототип для мониторинга ближайшего транспорта с фильтром направления, избранными остановками и картой на Leaflet.

## Запуск
1. Откройте `index.html` в браузере (локально или через любой статический хостинг).
2. Разрешите доступ к геолокации, чтобы карта и подсказки определяли ближайшие остановки.

## Что внутри
- Карточка «Прямо сейчас рядом» показывает ближайший маршрут, ETA и направление.
- Поиск/выбор остановки, переключатель направления «В мою сторону / Из моей стороны», кнопка обновления и добавления в избранное.
- Список прибытия и блок избранных остановок (хранится в `localStorage`).
- Карта Leaflet с метками остановок и транспорта, фильтрацией по направлению.
- Заготовка функции `fetchNearbyTransport` под интеграцию с API Яндекс Расписаний (ключ вынесен в константу `API_KEY`).

## Настройка API
В `index.html` внутри `fetchNearbyTransport` оставлен пример запроса к Яндекс Расписаниям. Подставьте рабочий API-ключ и эндпоинт, верните данные в формате `{ route, eta, direction, stopId, lat, lon }`.
