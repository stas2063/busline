# Busline

Одностраничный прототип для мониторинга ближайшего транспорта в Уфе с фильтром направления, избранными остановками и картой на Leaflet.

## Запуск
1. Откройте `index.html` в браузере (локально или через любой статический хостинг).
2. Разрешите доступ к геолокации, чтобы карта и подсказки определяли ближайшие остановки.

## Что внутри
- Карточка «Прямо сейчас рядом» показывает ближайший маршрут, ETA и направление.
- Поиск остановки (вводом с подсказками), поле номера маршрута (цифрами) с автоподсказками по популярным маршрутам Уфы и тем, что пришли из API, подбор двух конечных точек по выбранному маршруту вместо переключателя «в мою сторону», кнопка обновления и добавления в избранное.
- Список прибытия и блок избранных остановок (хранится в `localStorage`).
- Карта Leaflet с метками остановок и транспорта; направление определяется выбранной конечной.
- Привязан к городу Уфа: дефолтные координаты, мок-данные и API-запросы отфильтрованы по этому городу. Станции из API дополнительно отсеиваются гео-окружностью 35 км вокруг центра.
- Рабочий запрос `fetchNearbyTransport` к API Яндекс Расписаний (ключ вынесен в константу `API_KEY`).

## Настройка API
В `index.html` внутри `fetchNearbyTransport` используется ключ `API_KEY` и два запроса к Яндекс Расписаниям: ближайшие станции и их расписание. Если запрос успешен, статус в карточке помечается как «Данные по API Яндекс», при ошибке выполняется graceful fallback к локальным мок-данным.
