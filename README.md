# Busline

Одностраничный прототип для мониторинга ближайшего транспорта в Уфе с фильтром направления, избранными остановками и картой на Leaflet.

## Запуск
1. Откройте `index.html` в браузере (локально или через любой статический хостинг).
2. Разрешите доступ к геолокации, чтобы карта и подсказки определяли ближайшие остановки.

## Что внутри
- Карточка «Прямо сейчас рядом» показывает ближайший маршрут, ETA и направление.
- Поиск/выбор остановки, поле номера маршрута с автоподсказками, переключатель направления «В мою сторону / Из моей стороны», кнопка обновления и добавления в избранное.
- Список прибытия и блок избранных остановок (хранится в `localStorage`).
- Карта Leaflet с метками остановок и транспорта, фильтрацией по направлению.
- Привязан к городу Уфа: дефолтные координаты, мок-данные и API-запросы отфильтрованы по этому городу.
- Рабочий запрос `fetchNearbyTransport` к API Яндекс Расписаний (ключ вынесен в константу `API_KEY`).

## Настройка API
В `index.html` внутри `fetchNearbyTransport` используется ключ `API_KEY` и два запроса к Яндекс Расписаниям: ближайшие станции и их расписание. При ошибке выполняется graceful fallback к локальным мок-данным.
